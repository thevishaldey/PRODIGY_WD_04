PRODIGY_WD_04

Task 5 : Portfolio Website
This project is one of the many intern projects for Web Development Internship at Prodigy InfoTech. In this, we were supposed to make A responsive personal portfolio built with plain HTML, CSS and JavaScript. No frameworks, no build step, no dependencies. 
___________________________________________________________________________________________________________________________________________________________________________
✨ Features
- Hero that fits the screen. The heading, text, buttons and photo scale with the window so the first view never needs scrolling.
- Animated background. Slow drifting glows and a faint dot grid. It stays still for visitors who have reduced motion turned on.
- Light and dark mode. Follows the visitor's system setting, using CSS variables.
- Filterable skills. Skill cards for Web, Languages, Data and People, each linking to the projects where the skill was used.
- Project showcase. Links to three live apps built during a web development internship at Prodigy InfoTech:
     - Stopwatch App
     - Tic-Tac-Toe
     - Weather App
- Contact section. Gmail link, copy-to-clipboard buttons for email and phone, and a LinkedIn link.
- Accessible. Semantic HTML, visible keyboard focus, and labelled controls.
